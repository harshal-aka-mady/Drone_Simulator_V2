## What it is

A drone flight simulator for **RPTO training in India**, built as per DGCA guidelines: the Remote Pilot Certificate syllabus (DTC 02 of 2022) and the simulator requirements for RPTOs (DTC 01 of 2026). Trainees practise the RPTO test and the theory. RPTOs run the full course with grades, records and reports.

## New in V3.1.1

- **Arming as on a real drone:** throttle down + yaw right for 1 second, or both sticks down and in (throttle down + yaw right, pitch down + roll left). Disarm after landing: throttle down + yaw left.
- **Throttle centre in Radio setup:** set where your radio's throttle middle is, so it reads exactly 50 % and the drone hovers at mid stick.
- **Hands-on pre-flight check:** turn each motor by hand (a worn bearing grinds and stops), spot a chipped propeller or a cracked arm, and take the top cover off with **H** to check the battery.
- **Compass calibration, four ways:** six sides (Mission Planner), horizontal then vertical turn (DJI style), free rotation (Betaflight / INAV) and Large Vehicle MagCal. Pick one, see what it needs, then do it.
- **Motor test:** each motor's spin and airflow shown next to what it should do, with Switch and Replace propeller right below.

## Install

### Windows

1. Download `VoltairDroneSimulatorV3-Setup.exe` from [Releases](../../releases/latest) and run it.
2. If Windows SmartScreen shows a blue box, click **More info**, then **Run anyway**. The app is not yet signed with a paid certificate.
3. To update V3, close the game and run the new setup over the old one.

### macOS (Apple silicon)

1. Open `VoltairDroneSimulatorV3-mac.dmg` and drag **Voltair Drone Simulator V3** into **Applications**. Coming from Drone Trainer V3? Drag the old app to the Bin afterwards; your records stay.
2. First time only: right-click the app, choose **Open**, then **Open** again. On the newest macOS: **System Settings > Privacy & Security > Open Anyway**.

### Good to know

- Fly with the keyboard, or any RC radio, USB dongle or gamepad that the computer shows as a game controller (Mode 2).
- **Arm:** throttle down + yaw right for 1 second (keyboard: hold **D**). **Disarm:** throttle down + yaw left (keyboard: hold **A**).
- New radio? Open **Radio setup**, use Auto-setup, roll both sticks round the edge, then set the throttle centre.
- Full screen: **F11** on Windows, **Control + Command + F** on Mac.
- On a big screen or projector, open **Settings** (top right) for text size and screen shape.
